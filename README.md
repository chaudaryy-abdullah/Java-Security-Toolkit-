# Java-Security-Toolkit
A collection of production-ready Java security implementations — BCrypt hashing, AES-256-GCM encryption, RBAC, audit logging, brute-force protection, SQL injection prevention, and STRIDE threat modelling. Built from a real Hotel PMS project.
